The program in `main.py` validates the comment against the gate (UTF-8, 1–140 characters, a single line) and writes it to `entry.txt` in the output directory.

The comment:

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
